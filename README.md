# Диаском — главная страница

Статическая вёрстка: HTML, CSS, JS без сборки. Открыть `index.html` в браузере.

## Структура
- `index.html` — разметка страницы
- `css/style.css` — стили; цвета, шрифты и отступы вынесены в переменные `:root`
- `js/main.js` — бургер-меню, выпадающее меню, видеобаннер, слайдер проектов, бегущая строка логотипов, маска телефона, проверка формы
- `img/` — изображения в WebP; `img/icons/` — логотип и иконки (SVG); `img/partners/` — логотипы партнёров
- `video/` — видеобаннер: `hero.webm` (VP9) и `hero.mp4` (H.264)

## Видеобаннер
autoplay + muted + loop + playsinline (работает на iOS), играет только в зоне видимости.
При `prefers-reduced-motion` показывается постер.

## Адаптив
360–1920px. Брейкпоинты: 1360, 1200, 1024 (бургер-меню), 768, 600, 400.
